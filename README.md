# XAU/USD Liquidity Dashboard

A professional, live XAU/USD market dashboard with:

- live PAXG/USDT feed from Binance
- candlestick chart
- heatmap and volume profile overlays
- responsive trading layout
- modern dark dashboard styling

## Run locally

Open `index.html` directly in your browser, or serve the folder with a local static server:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Features

- Real-time market data via Binance WebSocket
- Multi-timeframe switching: 1m, 5m, 15m, 1h
- Liquidity heatmap and profile toggles
- Rich market statistics and session range
- Mobile-responsive layout

## Notes

This project is intentionally lightweight and does not require a build step.
